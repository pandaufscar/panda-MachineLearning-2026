# Minicurso – Introdução ao Machine Learning

## 📌 Sobre este minicurso

Este minicurso foi desenvolvido como parte das atividades do Grupo de Estudo de Machine Learning do Panda UFSCar, com o objetivo de apresentar os fundamentos de Machine Learning para a comunidade acadêmica.

O conteúdo é baseado no material desenvolvido ao longo das 17 semanas de estudo do grupo e oferece uma visão prática e acessível sobre os principais conceitos da área.

---

## 📅 Estrutura do Minicurso

O minicurso está organizado em **três encontros**, com um formato que combina fundamentos teóricos e aplicações práticas:

### Dia 1 – Fundamentos de Machine Learning
**Duração:** 1h30  

**Conteúdo programático:**
- O que é Machine Learning?
- Tipos de aprendizado (supervisionado, não supervisionado, reforço)
- Pipeline de um projeto de ML
- Análise Exploratória de Dados (EDA)
- Pré-processamento de dados
- Treinamento e avaliação de modelos
- Exemplo prático com Python e Scikit-learn

**Material de apoio:**
- Slides: `Minicurso_Introducao_ML.pdf`
- Notebook: `minicurso_ML_panda.ipynb`

## 🎯 Objetivos do Minicurso

Ao final do minicurso, espera-se que os participantes sejam capazes de:

- Compreender o que é Machine Learning e suas principais aplicações
- Diferenciar os tipos de aprendizado de máquina
- Entender as etapas de desenvolvimento de um projeto de ML
- Conhecer os principais algoritmos supervisionados
- Interpretar métricas utilizadas na avaliação de modelos
- Acompanhar a construção de um modelo prático utilizando Python e Scikit-learn
