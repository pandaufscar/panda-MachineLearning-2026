# Apresentação – Workshop Panda 2026

## 📌 Sobre esta pasta

Esta pasta contém os slides utilizados na apresentação do Grupo de Estudo de Machine Learning durante o **Workshop de Projetos Práticos Panda 2026**.

A apresentação foi desenvolvida ao longo das 17 semanas de estudo e consolida os principais conceitos aprendidos pelo grupo, servindo como material de referência para a comunidade acadêmica.

---

## 📁 Arquivos Disponíveis

| Arquivo | Descrição |
|---------|-----------|
| `Workshop_PANDA_Machine_Learning.pdf` | Slides completos da apresentação |
| `slides_workshop.pptx` | Versão editável dos slides (PowerPoint) |

---

## 📋 Conteúdo da Apresentação

A apresentação está organizada nos seguintes tópicos:

| Slide | Título | Descrição |
|-------|--------|-----------|
| 1 | Título | Abertura do Workshop |
| 2 | O que é Machine Learning? | Conceito e exemplos de utilização |
| 3 | Por que Machine Learning é importante? | Contexto e importância da área |
| 4 | Como um Computador aprende? | Processo de aprendizado de algoritmos |
| 5 | Tipos de Machine Learning | Supervisionado, Não Supervisionado e Reforço |
| 6 | O Pipeline de Machine Learning | Etapas de um projeto de ML |
| 7 | Análise Exploratória de Dados (EDA) | Importância e técnicas da EDA |
| 8 | Pré-processamento dos Dados | Tratamento de dados antes do treino |
| 9 | Treinando os modelos | Algoritmos estudados (Regressão Linear, Logística, Árvores, Random Forest) |
| 10 | Avaliação dos Modelos | Métricas de avaliação (Accuracy, Precision, Recall, F1) |
| 11 | Estudo de caso: Diabetes | Aplicação prática em um problema real |
| 12 | Comparação dos modelos | Como escolher o melhor modelo |
| 13 | Desafios em projetos de ML | Problemas comuns e como superá-los |
| 14 | O que desenvolvemos no grupo | Competências e conteúdos estudados |
| 15 | Considerações finais | Reflexão sobre o aprendizado |
| 16 | Agradecimentos | Encerramento |

## 🎯 Objetivo da Apresentação

- Apresentar os resultados do Grupo de Estudo de Machine Learning
- Demonstrar a evolução dos participantes ao longo das 17 semanas
- Compartilhar o conhecimento adquirido com a comunidade acadêmica
- Incentivar novos participantes a se envolverem com Machine Learning
